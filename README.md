# Реализация и исследование алгоритмов обучения агента в среде FrozenLake
Репозиторий содержит практическую работу по исследованию и сравнительному анализу классических табличных алгоритмов обучения с подкреплением в стохастической среде `FrozenLake-v1` (библиотека Gymnasium).

## Цель работы
Обучить агента в среде FrozenLake максимальным количеством различных алгоритмов обучения с подкреплением.

## Реализованные алгоритмы
В проекте реализовано **5 алгоритмов** обучения с подкреплением:
1. **Q-Learning** (Off-policy TD-контроль)
2. **SARSA** (On-policy TD-контроль)
3. **Expected SARSA** (Математическое ожидание следующего шага)
4. **Double Q-Learning** (Борьба с ошибкой переоценки / Maximization bias)
5. **Monte Carlo** (Офлайн-обновление на основе полных эпизодов)

## Условия экспериментов
Эксперименты проводились в условиях высокой стохастичности (скользкий лед, `is_slippery=True`).
* **Базовая среда:** Карта 4x4 (16 состояний) — 10 000 эпизодов.
* **Сложная среда:** Карта 8x8 (64 состояния) — 20 000 эпизодов.

В ходе работы генерируются графики кривых обучения и выводятся таблицы с итоговыми метриками (максимальный % побед, финальный % побед (в конце), время обучения).
